# سيد الاستغفار — حزمة الموقع

## الملفات
- `index.html`: الموقع الرئيسي.
- `manifest.webmanifest`: إعدادات التثبيت كتطبيق ويب.
- `sw.js`: التخزين المؤقت الأساسي للعمل دون اتصال بالملفات الأساسية.
- `icon.svg`: أيقونة الموقع.

## تشغيل محلي
افتح مجلد المشروع في محرر مثل VS Code، ثم شغّل خادمًا محليًا (مثلاً إضافة Live Server). لا يُنصح بفتح الملف مباشرة عبر `file://` لأن تحديد الموقع وService Worker يحتاجان إلى HTTPS أو localhost.

## النشر المجاني
يمكن نشر المجلد على GitHub Pages أو Netlify أو Cloudflare Pages:
1. ارفع الملفات الأربعة كما هي إلى مستودع أو مشروع استضافة ثابتة.
2. اجعل `index.html` في جذر النشر.
3. فعّل HTTPS.
4. افتح رابط الموقع على الهاتف، ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» حسب المتصفح.

## الخدمات الخارجية
- مواقيت الصلاة والتاريخ الهجري واتجاه القبلة: AlAdhan API.
- بيانات السور والتلاوة الصوتية: AlQuran Cloud API.
- الخطوط: Google Fonts.

## ملاحظات مهمة قبل النشر العام
- الموقع لا يحتوي على خادم خلفي أو قاعدة بيانات؛ بيانات السبحة والختمة تُحفظ محليًا على جهاز الزائر.
- التنبيهات الظاهرة حاليًا تطلب الإذن فقط؛ لا تدّعي هذه النسخة إرسال تنبيهات آلية دقيقة عند وقت الصلاة. يلزم خادم/جدولة إشعارات أو تطبيق أصلي لذلك.
- بوصلة القبلة إرشادية وتعتمد على الموقع والحساسات؛ يجب معايرة الهاتف والتحقق ميدانيًا.
- أوقات الصلاة تقديرية وفق طريقة الحساب المحددة في الطلب؛ راجع إعدادات الجهة الدينية المحلية قبل الاعتماد عليها.
- راجع نصوص الأذكار ومراجعها قبل الإطلاق العام، ويمكن توسيع مكتبة الأذكار بمصادر موثوقة.
- أزل أو حدّث بيانات المطوّر ووسيلة التواصل قبل النشر إذا رغبت.
